# 藤の栞 GitHub Pages 版

公開するのは `index.html`・`data.json`・`images/` だけです。`藤の栞_編集ツール.html` は公開せず、ご自身のPCで使用してください。

1. このZIPの中身を GitHub リポジトリ `Shideori/fuji-no-shiori` のルートへアップロード。
2. GitHub → Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save。
3. 公開URL: https://shideori.github.io/fuji-no-shiori/
4. 編集ツールをローカルで開き、登録・編集を行う。`公開用 data.json を書き出す` をクリック。
5. 書き出された `data.json` をリポジトリの同名ファイルに上書きしてコミット。公開側に反映されます。
6. 大量の画像は WebP/JPEG に圧縮し、GitHub リポジトリの `images/` に入れる。編集ツールの画像URL欄に `images/ファイル名.webp` を入力する。

**注意:** 編集ツールのブラウザ内保存は端末ローカルのみ。GitHub への自動同期ではありません。公開データは誰でも閲覧できます。画像を含め、GitHub Pagesの制限に注意。JSONをエクスポートしてバックアップを残してください。
